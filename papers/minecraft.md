## 📜 Server Rules

#### **1. 💚 Self Care**
If you need to eat, sleep, or handle real life - do it. No one will be upset that you logged off. This is a game, not a job. Take care of yourself first.

#### **2. 🚫 Server Damage**
Don't intentionally lag or crash the server. No lag machines, no chunk loaders spiraling out of control, nothing that makes it unplayable for others. If it's on purpose, it's an instant ban.

#### **3. 🤝 No Disrespect**
Keep it civil. Trash talk during PvP is one thing, but targeting someone personally or being excessively toxic will get you removed. People are here to relax.

#### **4. 💬 Conversations**
Keep chat clean. No sex, violence, politics, or hate speech. There are plenty of other places on the internet for that. This isn't one of them.

#### **5. ✋ Player Consent**
Before you grief, fight, raid, loot, or steal from another player - ask first. Consent can be given for war, PvP, raids, or sharing resources. If they say no, respect it. No exceptions.

#### **6. 🏠 Be Independent**
Build your own stuff. If you want to team up, both players need to agree. Don't just move into someone's base uninvited.

#### **7. 🔧 Hacks Allowed**
**Only on servers that permit it** (check each server's Rules line). Client mods are fine - X-ray, minimaps, sorting tools, shaders, whatever helps you play. The only catch is don't use them to damage the server or ruin someone else's experience without consent. For example, if you use X-ray and another player doesn't want you sharing the materials with them, you have to respect that.

#### **💤 Dormant Server Policy**
If a server I host sees no activity for **2 months**, I'll turn it off. After that, there's a **4-month grace period** - within that window you can ask me to turn it back on, or request a copy of the world file to keep your save. If no one asks within those 4 months, the server and its data are deleted for good. This applies to every server I host.

>>> 🔒 Security Policy

These servers run on hardware sitting in my house, so the safety of the machine and the people on it comes before convenience. Here's exactly what that means.

#### **💬 Chat Is Logged**
Every server I host logs in-game chat. Logs are kept so rule breaks, harassment, and grief disputes can actually be checked instead of argued about. Assume anything you type in chat is recorded and readable by staff. Use Discord DMs for anything you don't want on the record.

#### **💾 Backups**
Every server is backed up. If something breaks - a bad update, a corrupted chunk, a griefing incident - there's a restore point to roll back to. Backups also mean a dormant server's world can still be handed over during the grace period.

#### **🧩 Modpack Vetting**
Custom modpacks are reviewed **one mod at a time** before they go anywhere near the server. I check what each mod is, where it came from, and what it does. Mods run arbitrary code with full access to the machine hosting them - a single bad one is a compromise of the whole box and everyone's data on it.

#### **🚫 Untrusted Mods Are Rejected**
Anything I can't verify gets rejected. That includes unknown authors, reuploads, mods pulled from random sites instead of CurseForge or Modrinth, abandoned projects with no source, and anything obfuscated. No exceptions, and I won't explain past "I couldn't verify it."

**✅ To avoid a rejection, request popular, well-known modpacks.** Established packs on CurseForge or Modrinth with a large user base and an active maintainer have already been through thousands of people's machines. A pack someone assembled last week has not.
